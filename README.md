# Power Yoga Android App

Android wrapper around the supplied UXMagic Power Yoga web project.

## Build
Open this folder in Android Studio and run the `app` configuration, or run:

    gradle :app:assembleDebug

The APK is generated at `app/build/outputs/apk/debug/app-debug.apk`.

A GitHub Actions workflow is included and automatically produces the APK as a downloadable workflow artifact.
